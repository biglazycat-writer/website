## Meet BigLazyCat Writer

BigLazyCat Writer is a writing workspace for novelists, WeChat creators and content makers. Writing, research, AI assistance, mind maps, canvases, typeset export and publishing all live in one place. The desktop app supports Windows, macOS and Linux; an Android app is available for mobile.

- **Local-first**: one piece of writing is a standard Markdown file, a collection is a plain folder, mind maps are `.xmind`, canvases are `.canvas`. Any editor can open them, any cloud drive or Git repo can back them up — your work stays yours.
- **AI-first, model-agnostic**: connect mainstream model providers, any OpenAI-compatible endpoint, or local Claude / Codex commands. Built-in MCP lets AI create files, reshape outlines and handle formatting and publishing.
- **Buy once**: no subscription and no edition tiers on the desktop app. Start with a 30-day full-feature trial; after purchase every feature and future update is yours.
- **Open ecosystem**: official plugins add WeChat formatting, book-grade typeset export, OCR and speech. You can also build plugins around your own workflow.
